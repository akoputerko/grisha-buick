# Гришин бьюик

Страница с бьюиком, аниме-глазами и колесом фортуны. Четыре сектора «Да» и четыре «Нет», случайный результат, вращение, огни и конфетти. Звук включается отдельной кнопкой.

`index.html` содержит картинку, стили и скрипт. Его можно открыть в браузере или разместить на статическом хостинге. Установка зависимостей не нужна.

Для локального запуска из папки проекта:

```sh
python -m http.server 8000 --bind 0.0.0.0
```

`style.css` и `script.js` — отдельные копии для редактирования. После изменений их нужно также обновить внутри `index.html`.
